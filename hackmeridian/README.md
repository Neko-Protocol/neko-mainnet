# Neko at HackMeridian 2026

Builder track: **Scale**. Thematic track: **Stellar Composed**. Venue: ONE16, Lisbon.
Submission deadline: 26 Oct 2026, 12:00 WET.

This folder documents how the project was built during the event, session by session, so judges (human and AI) can follow the whole process.

| File                       | What it is                                                                    |
| -------------------------- | ----------------------------------------------------------------------------- |
| [plan.md](plan.md)         | The working plan: what we build, in what order, and what stays on the roadmap |
| [diagrams.md](diagrams.md) | Product flows (Mermaid)                                                       |
| [sessions/](sessions/)     | One log per work session: when it started and ended, what we did and decided  |

## How we log sessions

- Every session gets its own file: `sessions/session-NN.md`, copied from [`sessions/_template.md`](sessions/_template.md).
- Times are in WET (Lisbon, UTC+0).
- Each log says what was decided, what was built (with commit or PR links), what is still open, and how AI was used.
- Work done before the event is everything before the git tag `pre-hackmeridian`.
