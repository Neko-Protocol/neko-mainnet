# FK Grotesk (self-hosted)

Place your licensed **woff2** files here so the app can load them.

Expected filenames (adjust `globals.css` `@font-face` `src` if your export uses other names):

| Role | Weight | File |
|------|--------|------|
| Main | Light (300) | `FKGrotesk-Light.woff2` |
| Main | Regular (400) | `FKGrotesk-Regular.woff2` |
| Main | Medium (500) | `FKGrotesk-Medium.woff2` |
| Labels | Regular (400) | `FKGroteskSemiMono-Regular.woff2` |
| Labels | Medium (500) | `FKGroteskSemiMono-Medium.woff2` |

Until these files exist, the UI falls back to **Inter** (loaded from Google Fonts) and system fonts.

Use only copies you are licensed to distribute in your deployment.
